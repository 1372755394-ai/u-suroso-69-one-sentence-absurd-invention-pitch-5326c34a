One sentence pitching a ridiculous invention that fixes a tiny everyday annoyance: the Hamper of Shame, a laundry basket that sighs, photographs any sock left on the floor beside it, and posts the crime scene to your family group chat captioned "he lives like this."

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

`main.py` runs on Python 3.13 with the standard library only, and writes the one-sentence pitch (185 characters) to `/output/entry.txt`, checking on the way that it is a single sentence of 1–220 characters. No network, no input, deterministic — running it twice produces the same file.
